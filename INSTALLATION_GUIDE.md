# Easily Kitchen — Установка на Windows

## Часть 1: Установка на твой компьютер (без командной строки)

### Шаг 1: Установить Flutter (один раз)

1. Зайди на **flutter.dev/docs/get-started/install/windows**
2. Скачай архив Flutter SDK (кнопка "Download Flutter SDK")
3. Распакуй в папку `C:\flutter`
4. Открой **Параметры Windows → Система → О системе → Дополнительные параметры системы → Переменные среды**
5. В "Переменные пользователя" выбери `Path` → **Изменить** → **Создать** → вставь `C:\flutter\bin` → OK

### Шаг 2: Собрать приложение

1. Открой папку проекта `Home app\family_meal_planner` в **File Explorer**
2. Кликни в адресную строку проводника, напечатай `cmd`, нажми Enter — откроется командная строка уже в нужной папке
3. Скопируй и запусти три команды по очереди:
   ```
   flutter pub get
   dart run flutter_launcher_icons
   flutter build windows --release
   ```
4. Готово! Папка с приложением будет здесь:
   ```
   family_meal_planner\build\windows\x64\runner\Release\
   ```

### Шаг 3: Запустить как обычное приложение

В папке `Release\` есть файл **`easily_kitchen.exe`** — это и есть приложение.

Чтобы оно было удобно доступно:
- Правой кнопкой на `easily_kitchen.exe` → **Отправить → Рабочий стол (создать ярлык)**
- Или перетащи его на панель задач

> ⚠️ **Важно:** папку `Release\` не перемещай и не переименовывай — exe должен лежать рядом со своими файлами (`data\`, `flutter_windows.dll` и другими). Создавай только ярлык, а не переноси сам файл.

## Часть 2: Передать мужу (без командных строк у него)

Мужу не нужно ни Flutter, ни командная строка. Ему нужна только папка с готовым приложением.

### Способ А: Флешка или сетевая папка

1. Возьми папку `Release\` целиком (там примерно 50–80 МБ)
2. Скопируй мужу, например в `C:\Program Files\Easily Kitchen\` или просто в `Документы`
3. Создай ярлык на `easily_kitchen.exe` на рабочем столе

Готово — никаких установщиков не нужно.

### Способ Б: Создать ZIP-архив для передачи

1. Зайди в папку `Release\`
2. Выдели **все файлы и папки** внутри (Ctrl+A)
3. Правой кнопкой → **Отправить → Сжатая ZIP-папка**
4. Отправь ZIP мужу (через Telegram, почту, Google Drive, флешку)
5. Муж распаковывает архив в любую папку и запускает `easily_kitchen.exe`

### Способ В: Создать настоящий установщик (exe-инсталлятор)

Если хочется красивого установщика с меню "Установить / Удалить":

1. Скачай **Inno Setup**: **jrsoftware.org/isinfo.php** (бесплатно)
2. При первом запуске Inno Setup выбери **"Create a new script file using the Script Wizard"**
3. Заполни:
   - Application name: `Easily Kitchen`
   - Application version: `1.0`
   - Application folder name: `Easily Kitchen`
   - Main executable: укажи путь к `easily_kitchen.exe` из папки `Release\`
   - На шаге "Application Files" добавь **все файлы** из папки `Release\`
4. Нажми **Finish** → **Compile**
5. Получишь файл `setup.exe` — это полноценный установщик

Муж запускает `setup.exe`, нажимает "Далее" несколько раз, и приложение устанавливается с иконкой в меню Пуск.
